## 1. Product Overview
LunarByte科技公司官网，展示公司主营业务，提供沉浸式的宇宙探索体验。通过Three.js实现从地球到银河系的宏大视角转换，最终呈现信息于黑洞旁。

## 2. Core Features

### 2.1 Feature Module
1. **首页**: 3D宇宙探索动画、导航、公司信息展示
2. **业务模块**: 软件开发、服务托管、游戏开发帮助、AI agents帮助

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 首页 | 3D宇宙动画 | 从地球视角开始，滚动时依次缩小到太阳系、银河系、本星系群，再放大到仙女座星系中心，最终到达超大黑洞 |
| 首页 | 导航栏 | 固定顶部导航，平滑滚动到各个业务模块 |
| 首页 | 业务展示 | 在黑洞旁展示四大主营业务信息 |

## 3. Core Process
用户进入官网后看到地球外太空视角，通过滚动页面触发相机视角变化，依次浏览太阳系、银河系、本星系群，最终到达仙女座星系的超大黑洞旁，呈现公司业务信息。

## 4. User Interface Design
### 4.1 Design Style
- 主色调：全黑背景，白色文字，辅以蓝色/紫色星空点缀
- 字体：使用现代无衬线字体，强调科技感
- 布局：全屏沉浸式，3D场景为背景，文字信息悬浮于场景之上
- 风格：极简、科技、宇宙探索主题

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 首页 | 3D宇宙场景 | Three.js渲染的星系、星球、小行星、黑洞 |
| 首页 | 文字信息 | 白色无衬线字体，分层展示，随视角变化出现 |
| 首页 | 导航 | 固定顶部，简洁现代设计 |

### 4.3 Responsiveness
桌面端优先，自适应不同屏幕尺寸，保证3D场景在各种设备上的流畅运行。

### 4.4 3D Scene Guidance
- 环境：全黑宇宙背景，带星点效果
- 光照：主光源+环境光，营造太空氛围
- 相机：随滚动从地球逐渐拉远再聚焦到黑洞
- 动画：星球、小行星的自转和公转动画
- 交互：滚动触发相机视角变化
- 性能：使用LOD技术，保证帧率
